## Приложение для анализа банковских транзакций
Приложение генерирует JSON-ответы на основе данных, полученных из xlsx файла
Состоит из следующих модулей utils, report, services и views

### Модуль utils

Осуществляет основную логику проекта
1) Функция get_data() принимает путь к файлу с транзакциями, возвращает DataFrame с транзакциями для дальнейшей обработки

2) Функция date_split() принимает DataFrame с транзакциями, дату от пользователя и необязательный аргумент period для определения периода выборки операций. Возвращает DataFrame. Возможные значения аргумента period: M - месяц до даты пользователя. W - неделя на которую выпадает дата пользователя. Y - год до даты пользователя. ALL - все транзакции до даты пользователя
3) Функция get_spending() принимает DataFrame с транзакциями, возвращает словарь с парами Категония:Сумма операции
4) Функция get_user_stock() возвращает из json-файла с пользовательским настройками акции по которым в дальнейшем из внешнего API запрашивается цена
5) Функция stock_value() запрашивает от внешнего API стоимость акций по результатам выполнения функции get_user_stock(). Возвращает словарь с парами Акция:Цена акции

7) Функция sort_spending() принимает словарь с тратами по категориям от функции get_spending и производит сортировку основный расходов. Показывает первые семь и сумму остальных. Показывает поступления и операции по наличности и переводы. Добавляет ответы функций amount_exchange() и stock_value() к итоговому json-ответу.

### Модуль services

1) Функция user_search_discription() принимает DataFrame с транзакциями и ключевое слово от пользователя. Формирует json-ответ с транзакциями, в описании которых находит ключевое слово
2) Функция user_search_phone_namber() принимает DataFrame c транзакциями и возвращает json-ответ с транзакциями, содержащими номера телефонов

### Модуль reports
1) Функция spending_by_category() принимает DataFrame с транзакциями, ключевое слово от пользователя и опционально дату. Формирует json-ответ с тратами по категориям в которых есть ключевое слово. Если дата не передана, берется текущая дата
2) Декоратор log - выполняет логирование функции в указанный файл.
3) Декоратор log-simple - выполняет логирование функции в файл simple_log.log

### Модуль views

Содержит функцию main(). Принимает json-ответ от функций проекта, осуществляет запрос от пользователя информаций для сортировки

## Установка:
- требования:
```Python 3.12+```
- Клонируйте репозиторий:
```git@github.com:Alex-Winterfish/Skypro_course_work_1.git```
- Установите зависимости
```pip install -r requirements.txt```
```poetry add reguests```
```poetry add python-dotenv```
```poetry add pandas```
